Wind-up timer home screens (390 x 844 pt, iPhone)

svg/   Vector files. Import into Figma, Sketch, or Illustrator. Layers are grouped:
       background, header, settings-button, time-left, timer, unlock-button / lock-button, footer.
html/  The screens as web pages. Open in a browser (needs internet for the font).
png/   Flat images at 3x (1170 x 2532).
fonts/ Chivo variable font and its license (SIL OFL). Install it before opening the SVGs.

Type
  Chivo SemiBold (600) for all text, Chivo Medium (500) for the dial numbers.
  Time left: 112 pt, -3% tracking, tabular figures.
  Labels: 12 pt caps, 14% tracking. Date: 13 pt. Status line: 11 pt.
  Button: 17 pt.

Colour
  Ink           #1D1A16
  Secondary     #7A7163
  Red           #D2402A   (pointer, unlock button #E4553C to #C9391F, lip #97291A)
  Cream         #F2ECE1 to #D9CFBE background, #FFFEFB to #E2D9C9 plastic
  Unlocked text #B8361F

Figma import note
  Figma may turn the blurred shadows into layer blurs. It drops the faint plastic grain
  (an SVG noise filter); add a noise effect at about 5% if you want it back.
